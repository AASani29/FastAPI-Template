# PINNED LOW DELIBERATELY. passlib 1.7.4 (last released 2020) probes its bcrypt
# backend by reading `bcrypt.__about__`, removed in bcrypt 4.1, and by hashing a

# bcrypt 5.0.0 — verified, not theoretical. 4.0.1 is the last version that
# works. The real fix is migrating off passlib; see README trade-offs.
